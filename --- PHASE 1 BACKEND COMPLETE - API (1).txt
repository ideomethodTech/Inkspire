--- PUBLIC APIS (No Auth Required)
1. Health Check
bash
GET /health
Response: Returns service status (MongoDB, Firebase, all modules)

2. Product Catalog
bash
GET /api/products
Query Parameters:

page=1 (Pagination)

limit=10 (Items per page, max: 50)

category=Art|Nature (Filter by category)

type=poster|kit|sticker (Filter by type)

minPrice=100&maxPrice=1000 (Price range)

tags=nature,mountain (Comma-separated tags)

sort=newest|price_asc|price_desc|popular|name_asc|name_desc

3. Search Products
bash
GET /api/products/search?q=mountain

📝 RESPONSE FORMAT
Success Response:
json
{
  "success": true,
  "message": "Operation successful",
  "data": { ... }
}
Error Response:
json
{
  "success": false,
  "message": "Descriptive error message"
}
Common Error Messages:
"Authentication failed" - Invalid/missing JWT

"Insufficient stock" - Not enough quantity available

"Cart is empty" - No items in cart

"Order not found" - Invalid order ID

"Admin access only ❌" - User lacks admin role

--- FRONTEND INTEGRATION NOTES
1. Cart Management
Use variantIndex (0, 1, 2...) not _id for variants

Always check product.variants[].stock before allowing quantity selection

After order creation, cart will be empty - refetch it

2. Order Flow
Payment method is cod (Cash on Delivery) only in Phase 1

Shipping is free for orders above ₹500

18% GST is automatically calculated

Order numbers follow format: ORD-YYYYMMDD-XXX

3. Trending Products
Auto-updates based on last 7 days sales

Products become trending after being purchased

4. Filtering UI
Use /api/products/filters to populate dropdowns dynamically

All filters can be combined: ?category=Art&minPrice=100&maxPrice=1000&tags=nature&sort=price_asc

5. Authentication
JWT expires in 7 days

Store token securely (localStorage/sessionStorage)

Include in header: Authorization: Bearer <token>
